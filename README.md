# Formula Bar Partners — деплой в Telegram

## Что в этом наборе файлов

- `index.html` — твоё приложение. Я заменил локальное хранилище (`localStorage`) на запросы к серверу, чтобы владелец, продавцы и партнёры видели одни и те же данные с разных телефонов.
- `api/state.js` — серверная функция, которая хранит общее состояние приложения (список продавцов, партнёров, продаж, выплат).
- `api/withdrawal-request.js` — серверная функция, которая отправляет сообщение в Telegram, когда партнёр запрашивает вывод.
- `package.json` — нужен Vercel, чтобы правильно запускать серверные функции.

Всё это рассчитано на бесплатный деплой на **Vercel**.

---

## Шаг 1. Узнать chat_id, куда слать уведомления

Уведомления о заявках на вывод должны куда-то приходить — обычно это группа в Telegram, где сидят продавцы/владелец.

1. Создай группу в Telegram (или используй личный чат с ботом).
2. Добавь своего бота в эту группу (если это группа).
3. Напиши в группу любое сообщение.
4. Открой в браузере: `https://api.telegram.org/bot<ТВОЙ_ТОКЕН>/getUpdates` (вставь свой токен от @BotFather вместо `<ТВОЙ_ТОКЕН>`).
5. В ответе найди `"chat":{"id": -100123456789, ...}` — это число (может быть отрицательным) и есть нужный `chat_id`.

Сохрани этот `chat_id`, он понадобится на шаге 4.

## Шаг 2. Загрузить код на GitHub

1. Зайди на [github.com](https://github.com) и создай новый репозиторий (например `formula-bar-partners`), можно приватный.
2. Самый простой способ загрузить файлы без командной строки: на странице пустого репозитория нажми **"uploading an existing file"** и перетащи туда `index.html`, `package.json` и папку `api` (с обоими файлами внутри).
3. Закоммить изменения (кнопка "Commit changes").

---

## Шаг 3. Создать проект на Vercel

1. Зайди на [vercel.com](https://vercel.com) и зарегистрируйся/войди — проще всего через GitHub-аккаунт, тогда аккаунты сразу свяжутся.
2. Нажми **Add New → Project**.
3. Выбери репозиторий `formula-bar-partners`, который ты создал на шаге 2.
4. Framework Preset можно оставить "Other" — никаких build-команд не требуется, это статический сайт + serverless-функции.
5. Пока не нажимай Deploy — сначала добавь хранилище (шаг 4) и переменные окружения (шаг 5), либо добавь их сразу после первого деплоя и пересобери проект (Redeploy).

---

## Шаг 4. Подключить общее хранилище данных

Нужна простая база ключ-значение. Проще всего — через Marketplace-интеграцию Vercel с Upstash (есть бесплатный тариф).

1. В панели проекта на Vercel перейди в раздел **Storage**.
2. Выбери **Create Database** → найди **Upstash** (Redis) → создай базу на бесплатном тарифе.
3. После создания Vercel сам подставит переменные окружения вида `KV_REST_API_URL` и `KV_REST_API_TOKEN` в твой проект (это видно в Settings → Environment Variables — проверь, что они появились; если называются немного иначе, переименуй их в коде `api/state.js` или попроси меня подправить под точные имена, которые тебе выдал Upstash).

---

## Шаг 5. Добавить переменные окружения

В Vercel: **Project → Settings → Environment Variables**, добавь:

| Имя | Значение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен твоего бота от @BotFather |
| `TELEGRAM_CHAT_ID` | chat_id из шага 1 |
| `KV_REST_API_URL` | появится автоматически после шага 4 (проверь) |
| `KV_REST_API_TOKEN` | появится автоматически после шага 4 (проверь) |

После добавления переменных нажми **Deploy** (или **Redeploy**, если уже деплоил).

---

## Шаг 6. Получить ссылку и проверить

После деплоя Vercel выдаст ссылку вида `https://formula-bar-partners.vercel.app`. Открой её в браузере — приложение должно работать. Попробуй добавить продавца, выйти, и открыть ту же ссылку с другого устройства/браузера в режиме инкогнито — данные должны совпадать (это и есть проверка общего хранилища).

---

## Шаг 7. Подключить как Telegram Mini App

1. Напиши **@BotFather** в Telegram.
2. Команда `/mybots` → выбери свой бот.
3. **Bot Settings → Menu Button → Configure menu button**.
4. Введи текст кнопки (например "Открыть") и вставь ссылку с Vercel из шага 6.

Теперь у бота внизу чата появится кнопка, которая открывает твоё приложение прямо в Telegram.

(Альтернатива: команда `/newapp` у @BotFather создаёт отдельную Mini App с собственной короткой ссылкой `t.me/имябота/имяприложения` — удобно, если хочешь рассылать прямую ссылку отдельно от бота.)

## Важно знать перед запуском в реальную работу

- **Логотип**: в коде есть `<img src="formula-bar-logo.png">` — такого файла нет в этом наборе. Если у тебя есть логотип, добавь файл `formula-bar-logo.png` в корень репозитория рядом с `index.html`. Если нет — картинка будет просто не показываться, на работу приложения это не влияет.
- **Пароли в открытом виде**: сейчас пароли продавцов/партнёров/админов хранятся как обычный текст в общей базе данных и проверяются прямо в браузере. Это нормально для внутреннего MVP с доверенными людьми, но если в приложении будут крутиться серьёзные деньги или посторонние люди — стоит переделать авторизацию на серверную с хешированием паролей. Могу помочь с этим отдельно, если понадобится.
- **Owner PIN "7777"**: захардкожен в коде и виден любому, кто откроет исходники страницы (Ctrl+U в браузере). Для реального использования стоит хотя бы поменять его на что-то менее очевидное прямо в `index.html` (переменная `OWNER_PIN`).
- **Бесплатные лимиты**: Upstash и Vercel бесплатные тарифы рассчитаны на небольшую нагрузку — для одной партнёрской программы этого более чем достаточно.
